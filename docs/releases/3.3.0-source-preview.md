# v3.3.0 Source Preview

分析エクスプローラーの分類改善を追加しました。

- ドメイン境界・プロセス名による標準分類、既知ゲームのGaming分類
- チャンネルIDの完全一致分類。取得済みの同じIDなら表示名変更後も分類を維持
- 履歴からの区間補正／今後のルール作成、件数・時間・競合・手動補正の影響プレビュー
- 未分類の利用時間順一覧と、最大100対象の確認後の一括ルール保存

元のActivityは書き換えず、手動補正を優先して表示・集計します。プレビュー後の履歴・注釈・ルール変更は再確認を要求します。分類はローカルのルール処理で、AIや外部APIを使用しません。拡張機能は3.2.4を継続使用します。

ローカルでビルド、ブラウザ20ケース、C# 8スイート、WPF三テーマの人工データ画面・分類操作、統合テストを確認しました。GitHub側の最新検証は[Actions](https://github.com/axelose/PCActivityTracker/actions)で、このReleaseの対象コミットのCI／CodeQL結果を確認してください。実ブラウザ・Arm64実機・ゲームFPS・72時間常駐の合格証拠ではありません。

このプレリリースはソースコード用です。実行ファイル・インストーラーの添付はありません。証明書未取得のため、未署名の開発ZIPを一般配布せず、履歴DB・暗号鍵・ログ・個人の画面写真も含めていません。GitHubが生成するSource code ZIP／tar.gzから、READMEの手順に従って開発環境でビルドできます。

使い方はREADME「自動分類と未分類の整理」を参照してください。未知の対象はOtherに残します。カテゴリは成果・生産性の評価ではありません。ID未取得の履歴を推測統合せず、変更可能なYouTubeハンドル／Twitchログイン名について不変IDと同じ改名保証はしません。既存のAIレポート文章は必要に応じて手動で再生成してください。
