# v3.4.0 Source Preview

分析エクスプローラーの改善4～6を追加しました。

- 混在した時間枠のカテゴリ別時間と元の活動区間。別チャンネル・注釈を分離して選択・分類できます。
- 検索条件の保存・適用・削除（20件）、カテゴリ除外、全検索結果の集計。直前の同じ長さの期間と、同一条件・最新ルールで比較します。
- 未分類の選択項目へのローカルOllama分類候補。名称だけ・最大20件・手動実行・判断保留・形式検査・影響プレビュー後の選択承認制です。自動適用はありません。

元の自動記録は書き換えません。AI候補は一時表示だけで、承認したものだけがルールになります。AI分類は共通GPU排他、空きランタイム確認、最大2分、終了後の解放、既知／指定ゲームや画面・期間変更時の中止を使用します。URL・タイトル・チャンネルID・メモ・保存検索条件は分類AIへ渡しません。サイト内の内容・利用目的は推測できません。

ローカルのReleaseビルド、C# 9スイート、ブラウザ20ケース、WPF三テーマの人工データ画面・保存条件／AI承認操作、統合テスト、公開内容検査を実施しました。AIの回帰検証は模擬応答であり、実モデルの分類精度やゲームFPS、Arm64実機起動、72時間常駐の合格証拠ではありません。最新のGitHub側のCI／CodeQLは[Actions](https://github.com/axelose/PCActivityTracker/actions)で、このReleaseの対象コミットを確認してください。

ソースコード用プレリリースです。証明書未取得のため、未署名の開発実行ファイル・インストーラーは添付しません。履歴DB、暗号鍵、ログ、個人の画面写真も含めません。GitHubのSource code ZIP／tar.gzからREADMEの手順でビルドできます。対応拡張は3.2.4、DBスキーマは6のままです。

README「内訳・保存条件・AI分類候補」に操作方法・制限を記載しています。保存検索条件と承認済みルールはユーザー設定として保持され、履歴削除・保存期間では消えません。各画面から明示的に削除してください。進行中の期間や月の日数が異なる場合の比較にも注意してください。
